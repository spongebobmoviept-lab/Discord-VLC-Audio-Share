                    VLC DISCORD AUDIO SHARE - FULL SETUP GUIDE

PREREQUISITES
================================================================================

Before you start, you need 3 things:

1. VLC Media Player (FREE)
   • Download: https://www.videolan.org/vlc/
   • Install normally
   • You'll use this for streaming

2. VB-Audio Virtual Cable (FREE)
   • Download: https://vb-audio.com/Cable/
   • Install and RESTART your computer
   • This creates virtual audio devices for routing

3. Discord with Vencord (Optional but Recommended)
   • Discord: https://discord.com/download
   • Vencord: https://vencord.dev/
   • Vencord lets you use the "Share Screen hijack" for one-click streaming


STEP-BY-STEP SETUP
================================================================================

PHASE 1: Install Prerequisites (Do This First!)
-----------------------------------------------

1. Install VLC
   - Go to https://www.videolan.org/vlc/
   - Download VLC Media Player
   - Run installer, accept defaults
   - Finish

2. Install VB-Audio Virtual Cable
   - Go to https://vb-audio.com/Cable/
   - Download (free version is fine)
   - Run installer
   - IMPORTANT: RESTART YOUR COMPUTER
   - After restart, you should see "CABLE Input" and "CABLE Output" in audio devices

3. Install Discord (if you don't have it)
   - Go to https://discord.com/download
   - Download and install

4. Install Vencord (Optional - for "Share Screen" button hijack)
   - Go to https://vencord.dev/
   - Click "Install"
   - Choose your installer type
   - Follow the installation steps


PHASE 2: Configure VLC Share Tool
-----------------------------------

1. Extract the ZIP file you downloaded
   - Folder name: "VLC Discord audio Sharing Fix"
   - Contains: VLC Share Tool.exe, vlc_share_ctl.exe, VLCShare.tsx, etc.

2. Run VLC Share Tool.exe
   - Double-click it
   - A window will open with two tabs: "Monitors" and "Windows"

3. Pick What to Stream
   
   OPTION A: Stream a Monitor
   - Click "Monitors" tab
   - Select your monitor from the list
   - Usually the one labeled "PRIMARY: False" (if using dummy monitor)
   - Resolution should be your intended stream size
   
   OPTION B: Stream an App Window
   - Click "Windows" tab
   - Select the app you want to stream (Spotify, YouTube, OBS, game, etc.)
   - Make sure it's the right window

4. Configure Audio
   - Audio In: Set to "CABLE Output (VB-Audio Virtual Cable A)"
     (This is what VLC will READ audio from)
   
   - Audio Out: Set to "(none)"
     (This prevents audio bleeding through your speakers)

5. Save Configuration
   - Your settings are saved automatically
   - Close the window if you want

6. TEST: Launch VLC
   - Go back to VLC Share Tool
   - Click "Launch VLC"
   - A VLC window should open showing your selected monitor/window
   - You should see a video preview
   - Close VLC when done testing


PHASE 3: Route Audio to CABLE Input
-------------------------------------

This is the KEY step! Your app (Spotify, game, etc.) needs to output to CABLE Input.

SPOTIFY EXAMPLE:
- Open Spotify
- Settings → Devices → Select "CABLE Input (VB-Audio Virtual Cable)"
- Now when Spotify plays, audio goes into the cable

YOUTUBE / BROWSER:
- Windows Settings → Volume → Advanced → Volume mixer
- Find your browser in the list
- Change "Output device" to "CABLE Input"

GAME:
- Game Settings → Audio Output → Select "CABLE Input" or "VB-Audio"
- Or use Windows volume mixer (see YouTube example above)

OBS:
- Settings → Audio → Mic/Aux Audio Device → "CABLE Input"

ANY APP:
- Windows Settings → Sound → Volume mixer
- Find the app in the list
- Change "Output device" to "CABLE Input"


PHASE 4: Ready to Stream!
--------------------------

NOW YOU CAN START STREAMING:

1. Set up your app (Spotify playing, YouTube open, game running, etc.)

2. Route that app's audio to CABLE Input (see Phase 3 above)

3. Open VLC Share Tool and click "Launch VLC"

4. In Discord:
   - Join a voice channel
   - Click "Share Screen" button
   - Choose "Application Window"
   - Select "VLC" from the list
   - Click "Go Live"

5. Your friends can now:
   - SEE your monitor/window content
   - HEAR the perfect audio with no echo or bleed

6. To stop: Click "Stop Sharing" in Discord


OPTIONAL: VENCORD PLUGIN SETUP
================================================================================

If you installed Vencord, you can make "Share Screen" launch VLC automatically!

1. Copy the Plugin File
   - Find: VLCShare.tsx (in your extracted folder)
   - Copy it

2. Paste into Vencord
   - Open File Explorer
   - Paste this in address bar: %APPDATA%\Vencord\src\userplugins\
   - Right-click → Paste
   - VLCShare.tsx should now be in that folder

3. Restart Discord
   - Close Discord completely
   - Wait 2 seconds
   - Reopen Discord

4. Enable the Plugin
   - In Discord, click gear icon (Vencord settings) → bottom left
   - Go to "Plugins" tab
   - Search for "VLC"
   - You should see "VLC Share"
   - Toggle it ON (blue)

5. NOW: When you click "Share Screen"
   - VLC launches automatically with your settings!
   - You just select "Application Window → VLC → Go Live"
   - ONE CLICK setup instead of manual!


TROUBLESHOOTING
================================================================================

PROBLEM: "No audio coming through"
SOLUTION:
- Make sure your app is set to output to "CABLE Input"
- Check VLC Share Tool has "Audio In" = "CABLE Output"
- Restart the app after changing audio output

PROBLEM: "Audio is echoing / I hear double audio"
SOLUTION:
- Set "Audio Out" to "(none)" in VLC Share Tool
- This prevents VLC from playing audio locally

PROBLEM: "VLC not showing in Discord share list"
SOLUTION:
- Click "Launch VLC" in VLC Share Tool first
- Wait 2 seconds
- Then go to Discord Share Screen menu

PROBLEM: "Monitor not showing up in Monitors list"
SOLUTION:
- You have a dummy monitor / virtual monitor
- It might need drivers (search: dummy HDMI plug drivers)
- Or restart VLC Share Tool to refresh the list

PROBLEM: "Vencord plugin not showing"
SOLUTION:
- Restart Discord COMPLETELY (close from taskbar)
- Wait 5 seconds
- Reopen Discord
- Check Vencord settings again
