# VLC Share Tool - Setup Guide

## Quick Start (60 seconds)

### 1. Extract the ZIP file
Unzip `VLC-Discord-Share-Tool.zip` to a folder on your computer.

### 2. Install Vencord Plugin (Optional but Recommended)
Double-click `Setup Vencord Plugin.bat` in the extracted folder. It will:
- Create the Vencord plugins folder
- Copy the VLC Share plugin there
- Show you next steps

### 3. Restart Discord
Close Discord completely (right-click taskbar icon → Close), then reopen it.

### 4. Enable the Plugin
1. Open Discord
2. Click the **gear icon** in the bottom-left corner (Vencord settings)
3. Go to **Plugins** tab
4. Search for "VLC Share Tool"
5. Toggle it **ON**

### 5. Use It!

**Option A: From Discord (if plugin is installed)**
- Type `/vlc_share` → Opens VLC Share Tool GUI
- Type `/vlc_toggle` → Starts/stops VLC stream

**Option B: Direct Launch**
- Double-click `VLC Share Tool.exe` to open GUI

**Option C: Stream Deck Integration**
- Use `vlc_share_ctl.exe` with Stream Deck buttons

## Setting Up Your Stream

### Step 1: Configure VLC Share Tool
1. **Monitors tab** (or **Windows tab** to capture an app)
   - Pick your monitor/window from the list
   
2. **Monitors tab** - Set audio:
   - **Audio In**: `CABLE Output` (or your virtual cable device)
   - **Audio Out**: `(none)` (so you don't hear audio bleed)

3. Click **Launch VLC** → VLC window will open

### Step 2: Configure Discord
1. In Discord voice channel, click **Share Screen**
2. Select **Application Window**
3. Choose **VLC** from the list
4. Click **Go Live**

### Step 3: Control Volume
- **In Discord**: VLC window shows a volume slider at the bottom
- **From listeners**: They can right-click your name → User Volume to adjust their receive level

## Troubleshooting

### Vencord Plugin not showing?
- Restart Discord completely (not just minimize)
- Check that `Setup Vencord Plugin.bat` ran successfully
- Verify Vencord is installed: https://vencord.dev

### VLC not starting?
- Make sure VLC is installed: https://www.videolan.org/vlc/
- VLC must be accessible from system PATH or registry

### No audio from VLC?
- Verify **Audio In** is set to your virtual cable device (e.g., CABLE Output)
- Check that your app (Spotify, game, etc.) is routing audio to `CABLE Input`

### Can't find VLC in Discord share list?
- Click **Launch VLC** first in VLC Share Tool
- Wait 2 seconds, then go back to Discord share menu

## What You Can Stream

✅ **Monitors** - Any display (including dummy plugs, virtual monitors)
✅ **Application Windows** - Spotify, YouTube, games, OBS, browsers, etc.
✅ **Desktop** - Full screen capture of a specific monitor
✅ **Audio** - Complete control via VB-Audio Virtual Cable routing
